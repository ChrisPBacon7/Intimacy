# Intimacy Tattoo App - AI Context & Constraints

## Project Overview
This repository contains a simple invoice generation application built for a "Kleinunternehmer" (small business owner in Germany, no VAT collected) tattoo artist named Intimacy. The application relies on `Streamlit` for a quick and interactive frontend, `SQLModel` combined with `SQLite` for persistent storage, and `Jinja2` with `WeasyPrint` to generate formatted A4 PDF invoices.

### Dependencies
Managed completely by `PDM`.

Dependencies list:
- `streamlit`
- `sqlmodel`
- `pydantic==2.8.2` (To prevent namespace conflict with `sqlmodel` v0.0.38)
- `pandas`
- `jinja2`
- `weasyprint`

### Key Requirements Implemented
1. **Database & Fields**: Each invoice requires a customer name, address, service description, total amount, down payment amount (default 50€), down payment method (3 choices), final payment method, and a generated flag. ID is autogenerated.
2. **Template**: A structured HTML/CSS file `templates/invoice.html` is used. It features a space for a logo, shop details, total calculations, and a specific paragraph for the Kleinunternehmerregelung.
3. **Data Editor**: `st.data_editor` allows dynamic adding/deleting rows while syncing with the backend on a button click.
4. **PDF Output**: Clicking generate pushes the specific records to `pdf_generator.py` generating PDFs to the local `invoices/` directory, surfacing them via Streamlit download buttons.
